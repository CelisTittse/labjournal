1 Alleluia similarity search

Two models have arrived from the literature mainly Riccardo’s 2025 paper and Gleb’s 2025 paper (which also cites Riccardo). Sermons probabily travel in clusters, or blocks. These blocks could be arranged and changed fitting its historical context best, by adding, changing of switching sets of sermons or its contents (a phenomena observed in homiliaries in the 9th and 10th century). Historical collections (HC) of sermons are also sets of sermons, or the arrangement of sets of sermons.

Asking Shari, Gert, and Kendall resulted in the observation that manuscripts that contain a HC have three or four sermons in them within the same sequence. For now, we will say >3 sermons in sequence.

The simple question is:

1.1 How many manuscripts contain blocks of 3 or more sermons from the De Alleluia collection?

This first interrogation will be performed with the SERMONES FILE (SF), due to convience, and can later be connected to HOWA data to reduce the number of cleaning steps.

It must be stressed that it is possible to find a lot of false positives, because SF only describes authenitic augustinian sermons, and as Iris has described the percived authenticity is far more important than authenticity, hugely influencing the transmission and compilation process.

1.2 Can we cluster the manuscripts that we found based on their content?

This is a simple UMAP clustering based on basic normalised levenshtein distance, coloured by century, and size.

# 3. Find blocks of Alleluia sermons in one manuscript

# Strict: the sermons follow each other directly in the manuscript.
strict_runs <- function(s, A) {
  from <- integer()
  to   <- integer()

  for (i in seq_along(A)) {
    for (pos in which(s == A[i])) {      # every place where a run could start
      j <- i
      while (j < length(A) && pos < length(s) && s[pos + 1] == A[j + 1]) {
        pos <- pos + 1
        j   <- j + 1
      }
      from <- c(from, i)
      to   <- c(to, j)
    }
  }
  list(from = from, to = to)
}

# Ordered: the sermons keep the collection order, other sermons may stand in between.
ordered_runs <- function(s, A) {
  to <- rep(NA_integer_, length(A))

  for (i in seq_along(A)) {
    pos <- match(A[i], s)                # the earliest occurrence gives the longest chain
    if (is.na(pos)) next
    j <- i
    while (j < length(A)) {
      pos <- pos + match(A[j + 1], tail(s, -pos))   # next occurrence of the following sermon
      if (is.na(pos)) break
      j <- j + 1
    }
    to[i] <- j
  }
  list(from = seq_along(A), to = to)
}

# Returns every block of at least min_len sermons, written as "A1, A2, A3".
# Shorter blocks that lie inside a longer block are dropped.
find_sequences <- function(s, A, allow_gaps = FALSE, min_len = 3) {
  s <- s[!is.na(s) & nzchar(s)]
  if (sum(s %in% A) < min_len) return(character())   # quick exit for most manuscripts

  runs <- if (allow_gaps) ordered_runs(s, A) else strict_runs(s, A)
  long <- which(runs$to - runs$from + 1 >= min_len)    # which() also skips the NA rows
  o    <- long[order(runs$from[long], -runs$to[long])]  # sorted by start, longest first
  from <- runs$from[o]
  to   <- runs$to[o]

  # keep only the longest blocks: a block survives when it reaches past every earlier block
  longest <- to > c(0, head(cummax(to), -1))

  blocks <- map2_chr(from[longest], to[longest], ~ paste(A[.x:.y], collapse = ", "))
  unique(blocks)                         # a repeated sermon can give the same block twice
}
