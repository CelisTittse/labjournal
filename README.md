# Lab Journal for paper on Augustinian De Alleluia sermon Collection

This lab journal can be found on https://celistittse.github.io/labjournal/. 

It is the result of documentation of a Social Networks Course by Jochem Tolsma. 
The inquiry investiguates the transmission of the De Alleluia collection throughout the middle ages (400-1700). 
To this end, it utilises RSiena (SAOM) and block indentifies.

This research entails the exploratory collaborative endeavour of quantitative methods (by me), qualitative methods (by Kendall Bitcher), and an academic peer-brainstorm for a theoreatical framework for the transmission of sermon collections.
